Pertanyaan umum

Berapa lama prosesnya?

Via username dan gamepass biasanya diproses setelah pembayaran dikonfirmasi. Via login bisa lebih cepat, tergantung antrean admin.

Kenapa harga gamepass harus lebih besar dari Robux yang diterima?

Roblox memotong 30% dari setiap penjualan gamepass. Karena itu, untuk menerima 1.000 Robux, gamepass perlu diberi harga sekitar 1.429 Robux. Formulir di atas menghitungnya otomatis.

Apakah aman memberikan data login?

Kami menyarankan via username atau gamepass jika kamu ingin lebih aman. Jika memilih via login, kirim password hanya di chat WhatsApp dengan admin, dan ganti password setelah pesanan selesai.

Bagaimana cara pembayarannya?

Admin akan mengirim pilihan pembayaran (transfer bank atau e-wallet) setelah pesananmu masuk lewat WhatsApp.

Siap top up Robux?

Isi pesanan dalam satu menit, sisanya diurus admin lewat WhatsApp.
